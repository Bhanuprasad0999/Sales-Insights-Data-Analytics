# 📊 Sales Insights Data Analytics Project

## 📝 Project Overview
This project focuses on analyzing sales data for a manufacturing company to uncover key business trends. By building an end-to-end data pipeline, I transformed raw data into actionable insights using Excel, MySQL, and Power BI.

## 🛠️ Tech Stack & Tools
* **Excel:** Data cleaning and initial exploration (ETL).
* **MySQL:** Database management and deep-dive SQL querying.
* **Power BI:** Interactive dashboarding and data visualization.

## 🚀 Key Implementation Steps
1. **Data Cleaning:** Normalizing currency and removing anomalies in Excel.
2. **Database Management:** Star schema design and data import in MySQL.
3. **Visualization:** Developed dynamic dashboards to track Revenue, Profit, and Regional growth.

## 📂 Repository Structure
* `sales_cleaned.csv`: Cleaned dataset.
* `sales_insights.sql`: Database backup file.
* `sales_insights.pbix`: Power BI dashboard file.
